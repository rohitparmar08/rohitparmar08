## 🧩 Featured projects

### 🧑‍💼 [HireFlow: AI Resume Screening &amp; ATS](https://github.com/rohitparmar08/hireflow)
Role-based recruitment platform with separate recruiter and candidate portals.
- Explainable match engine (scikit-learn): scores each resume 0 to 100 on required skills, optional skills, TF-IDF similarity, experience and education, and shows matched and missing skills.
- 15+ REST APIs with JWT authentication (token rotation, logout blacklisting) and object-level permissions.
- Rate limiting, upload validation, resumes also stored in PostgreSQL, **61 automated tests**, GitHub Actions CI.
- **Stack:** Django REST Framework, PostgreSQL, React, Vite, Tailwind CSS, Render, Neon.

### 📚 [KnowFlow AI: RAG Document Q&amp;A](https://github.com/rohitparmar08/knowflow-ai)
Ask questions about your own documents and get cited answers from Gemini.
- Pipeline: chunking, 768-dimension Gemini embeddings in **pgvector**, cosine retrieval with a tuned 0.45 distance cutoff so off-topic questions skip the LLM.
- 20+ REST APIs with JWT authentication and per-user data isolation, fallback model for upstream errors.
- **75 automated tests**, GitHub Actions CI.
- **Stack:** Django REST Framework, PostgreSQL + pgvector, React, Gemini API, Render, Neon, Vercel.

### 💳 [SplitEase: Split Expenses &amp; Debt Simplification](https://github.com/rohitparmar08/splitease)
Full-stack expense sharing app built around transactional integrity.
- 15+ REST endpoints with JWT authentication and object-level permissions.
- Backend money math with Python `Decimal` across Equal, Exact, Percentage and Shares splits.
- Greedy minimum cash flow algorithm that reduces group debts to the fewest direct payments.
- ACID guarantees with PostgreSQL and `@transaction.atomic`, covered by `pytest`.
- **Stack:** Django REST Framework, React, PostgreSQL, JWT, Recharts, Swagger.

### 📄 [Intelligent Document Verification System](https://github.com/rohitparmar08/Intelligent-Document-Verification-System)
Django app that checks document image quality and extracts details with OCR.
- Quality checks: blur (Laplacian variance), noise, brightness and resolution.
- OpenCV + EasyOCR pipeline with downloadable JSON and PDF verification reports.
- **Stack:** Python, Django, OpenCV, EasyOCR, Bootstrap, SQLite.
